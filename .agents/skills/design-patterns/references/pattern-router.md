# Pattern Router

- Object creation varies or is expensive: read `creational.md`.
- Code needs adaptation, wrapping, composition, or stable interface boundaries: read `structural.md`.
- Behavior changes by state, command, event, or policy: read `behavioral.md`.
- System/module boundaries are the concern: read `architecture-patterns.md`.
- The request is a critique or refactor from messy code: read `anti-patterns.md`.

Do not load every pattern family by default.
