# Structural Patterns

## Adapter

Use to isolate external APIs or legacy interfaces behind a local shape.

## Facade

Use to simplify a complex subsystem for common callers. Avoid hiding important failure modes.

## Decorator

Use to add behavior around an interface without changing the core implementation.

## Proxy

Use for lazy loading, access control, caching, or remote boundaries. Avoid when it obscures expensive behavior.

## Composite

Use when callers should treat individual and grouped objects uniformly.
