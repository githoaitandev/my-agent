# Behavioral Patterns

## Strategy

Use when an algorithm or policy varies behind a stable interface.

## Command

Use when actions need queuing, retry, undo, logging, or transport.

## Observer / Publish-Subscribe

Use for event notification. Watch for hidden coupling and ordering assumptions.

## State

Use when behavior changes by lifecycle state and conditionals are spreading.

## Template Method

Use when a stable algorithm has extension points. Prefer composition when inheritance would be awkward.

## Chain Of Responsibility

Use for ordered handlers such as middleware, validation, or request processing.
