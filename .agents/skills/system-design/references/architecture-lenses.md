# Architecture Lenses

- Requirements: users, use cases, constraints, non-goals.
- Boundaries: clients, services, modules, external systems, trust boundaries.
- Data: ownership, schema, lifecycle, migrations, consistency, retention.
- Control flow: sync vs async, queues, retries, idempotency, ordering.
- Reliability: partial failure, fallback, timeout, circuit breaking, recovery.
- Scale: throughput, latency, fanout, hotspots, caching, backpressure.
- Security: authn, authz, secrets, data exposure, abuse paths.
- Operability: logs, metrics, traces, dashboards, runbooks, alerting.
- Evolution: migration path, compatibility, versioning, reversibility.
