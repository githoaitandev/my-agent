# Session Formats

Choose the smallest format that fits the user's intent.

## Quick Recall

Use for short practice.

```text
Mode: Active Recall

Question:
...
```

After the user answers:

```text
Assessment:
- Correct: ...
- Missing: ...

Follow-up:
...
```

## Newbie Training Simulation

Use when the user prepares to train a new member.

```text
Mode: Newbie Simulator + Teach-Back

First, explain <topic> as if I just joined the team.
I will stop when a term, step, or assumption is unclear.
```

End with:

```text
Training gaps:
- ...

Examples to prepare:
- ...

Next trainee question:
...
```

## Critical Explanation Review

Use when the user wants a hard critique.

```text
Mode: Critical Trainee

Claim or explanation under review:
...

Challenges:
- ...

Hardest question:
...
```

## Scenario Drill

Use when the user knows definitions but needs practice applying them.

```text
Mode: Scenario Drill

Scenario:
...

Question:
What would you do first, and why?
```

After the user answers:

```text
Assessment:
- Good decision: ...
- Risk: ...
- Better next step: ...

Constraint added:
...
```

## Knowledge Extraction

Use when the user wants to convert personal knowledge into training material.

```text
Mode: Gap Finder + Teach-Back

Knowledge map:
- Core concepts:
- Local practices:
- Common mistakes:
- Debugging heuristics:
- Examples:
- Exercises:

Next extraction question:
...
```
